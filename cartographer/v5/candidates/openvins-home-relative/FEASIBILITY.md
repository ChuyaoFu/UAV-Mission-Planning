# First feasibility audit — optional persistent estimated home clone

Verdict: feasible in the audited pin, subject to native core equivalence and root full estimator replay. Do NOT retain home in `_clones_IMU` forever: that map controls oldest-frame feature selection, anchor change, measurement cleanup and window size. Instead retain the existing first real clone pointer in a separate State member. At ordinary removal, erase its recent-map entry exactly as before, but preserve that variable in `_variables` and its original full covariance rows/columns. No duplicated independent prior, inserted home measurement, reset or covariance subtraction. At most six extra state dimensions after normal window eviction; recent window remains11.

Audited paths: StateHelper::augment_clone creates first real estimated PoseJPL, including existing time-offset augmentation. StateHelper::marginalize_old_clone is called both during asynchronous initialization catch-up and normal feature cleanup. Generic StateHelper::marginalize is also called by the explicit zero-motion branch of UpdaterZeroVelocity: a central retained-home check covers that existing deletion path while its caller still erases the recent-map entry. Current default explicit-zero-motion branch is hardcoded false, but must not rely on that for correctness. Other marginalization is SLAM landmark deletion, whose objects cannot equal the retained PoseJPL pointer.

EKFPropagation computes cross terms for all covariance rows; retaining home automatically propagates home-current cross covariance. EKFUpdate loops all `_variables`, so home mean and cross covariance receive the ordinary posterior update through correlation. Measurements/Jacobians are selected from the unchanged recent-map/features. For the same active measurement system and initial active marginal, the active Kalman gain and active posterior marginal are algebraically unchanged by retaining an unmeasured correlated variable. Actual floating arithmetic can differ by roundoff because matrix dimensions differ. This must be verified against the same native operations and then full replay; no physical equivalence claim before root grading.

SLAM reanchoring uses the unchanged recent-map oldest time before eviction, so it must remain before the retained-home removal check exactly as in baseline. StateHelper delayed initialization uses full covariance cross terms and may update home; active marginals should remain equal. No modifications to frontend, gates, noise, FEJ, initializer prior or recent clone limit are required. Simulation GT initialization is not used by this work.

Publisher design (updated for root's gravity requirement): separate optional `home_relative_body_pose` PoseWithCovarianceStamped, default off, no fabricated twist. Current state IMU pose rather than stale last clone shares exactly the original pose timestamp, including ZUPT. Explicit fixed T_IMU_BODY includes the body lever. Home origin is initial estimated BODY position. Orientation of H is ONLY yaw(R_W_Ihome*R_I_BODY); global Z remains gravity-up. No assumption initial BODY is level. Body and IMU origins must not be confused or double-corrected downstream. Metadata publishes anchor epoch and T_IMU_BODY; frame id explicitly says home_yaw_bodyorigin.
