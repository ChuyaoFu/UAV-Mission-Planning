## Twist covariance assessment — deferred, not silently corrected

The existing cache15x15 covariance is available. For fixed known IMU intrinsics a local-velocity Jacobian can include skew(v_I)*dtheta_I + R_GI*dv_G, and bias-corrected gyro can include −G*dbg + G*Tg*A*dba with G=R_GYROtoIMU*Dw, A=R_ACCtoIMU*Da. A combined6x15 Jacobian would retain v/angle/bg/ba cross terms. But last gyro/accel measurement noises have already entered cached propagation, so their correlation with the state must not be declared independent. A proven Young PSD enclosure is possible for specified error models; online intrinsic calibration and time uncertainty require additional cross terms beyond the cache15.

That would change native velocity/angular covariance semantics and require separate conditional configuration/qualification and complete6x6 validation. It is not part of this time-only patch. Existing native angular covariance remains gyro-white-noise/dt and omits bias/cross terms (native TODO); local v covariance remains its legacy approximation. Root's adapter should continue to label it nativeapprox+motion guard, not formal complete posterior. No rushed API or covariance-mode extension here.
